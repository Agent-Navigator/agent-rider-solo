## Gotchas learned this session
- pkill -f with a pattern that appears in your own bash -c command kills your
  own shell — kill by PID instead.
- xpra stop does NOT kill the session script loop; fixed in
  scripts/start-gnome-flashback-session.sh (xset q probe). KasmVNC's vncserver
  -kill :101 kills Xvnc, and the loop now exits itself when X dies.
- The old xpra input bugs (paste bubble on every click = _poll_clipboard
  calling navigator.clipboard.readText; unbalanced button releases) are all
  patched in plugins/local-desktop/inputBridge.ts — none of that applies to
  KasmVNC.
- KasmVNC prints "https://..." on start but serves plain http (protocol: http
  in kasmvnc.yaml) — that's expected.
